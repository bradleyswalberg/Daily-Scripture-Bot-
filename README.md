# Daily Verse Bot

Sends one verse about Jesus Christ from the Book of Mormon to a Discord
channel every da along with a short note on how it applies

## Files
- `verses.json` - the 30 verses and notes
- `daily_verse_bot.py` - picks today's verse and sends it
- `.github/workflows/daily_verse.yml` - runs the script automatically every day
- `requirements.txt` - the one package this needs (`requests`)
